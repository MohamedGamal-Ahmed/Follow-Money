# Follow Money — مركز الدعم

**تابع صرفك وتحويلاتك والتزاماتك، وافهم الأرقام من العمليات اللي وراها.**

Follow Money تطبيق Android بواجهة عربية، يجمع العمليات من رسائل البنوك وإشعارات تطبيقات الدفع المدعومة، مع إضافة وتعديل يدوي ومراجعة للمصادر.

هذا المستودع مخصص للدعم واقتراح التحسينات. كود التطبيق خاص، ولا توجد ملفات مصدر التطبيق هنا. إرسال بلاغ لا يحتاج دعوة أو صلاحية على كود البرنامج؛ فقط حساب GitHub.

## قبل إرسال بلاغ

1. ابحث عن بلاغ مشابه لتجنب التكرار.
2. اكتب خطوات المشكلة والنتيجة المتوقعة والفعلية.
3. أضف نسخة التطبيق ونوع الجهاز ونسخة Android.
4. استخدم أمثلة وهمية وصورًا بعد إخفاء البيانات الشخصية.

**البلاغات والتعليقات والصور هنا عامة.** لا ترفع رسائل بنك أصلية، أرقام حسابات أو بطاقات أو OTP، قاعدة بيانات، CSV مالي أو سجلات جهاز كاملة. التطبيق لا يرفق معاملاتك تلقائيًا.

## حدود الأرقام

الأرقام تعكس العمليات المسجلة التي تعرّف عليها التطبيق؛ ليست كشف حساب بنكيًا كاملًا. التحويل بين حساباتك، دفع الأقساط، والمصروف اليومي أنواع مختلفة. العملات تُعرض منفصلة، والرصيد المحسوب من العمليات يُوسم بأنه تقديري. راجع العمليات غير المصنفة والاقتراحات قبل اعتمادها.

لا يوجد موعد ثابت مضمون للرد أو تنفيذ كل اقتراح. ميزات التطبيق قيد التطوير؛ هذا المستودع ليس صفحة شراء أو قناة لتوزيع نسخة موقعة.
