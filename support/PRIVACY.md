# البيانات والخصوصية

العمليات والحسابات والالتزامات محفوظة محليًا في التطبيق. لا توجد خدمة مزامنة أو حساب داخل التطبيق أو تحليلات استخدام ترسل معاملاتك.

نص مصدر العملية المحفوظ مشفر باستخدام Android Keystore؛ قاعدة بيانات المعاملات نفسها ليست مشفرة. إعدادات التطبيق تعطل Android backup؛ لا يعتبر ذلك ضمانًا ضد نسخ البيانات من جهاز معدل أو مخترق.

قراءة الرسائل أو إشعارات تطبيقات الدفع تحتاج صلاحيات Android واختيار المستخدم. الصيغ غير المدعومة قد لا تُلتقط. تصدير CSV اختياري ويحتوي على بيانات مالية؛ تعامل مع الملف كبيانات خاصة.

## الإبلاغ عبر GitHub

عند الضغط على الإبلاغ، يعرض التطبيق:

- نسخة Follow Money ورقم البناء.
- الشركة المصنعة وطراز الجهاز.
- نسخة Android ورقم API.
- اللغة/المنطقة المحددة للجهاز.

بعد موافقتك على فتح الفورم، تُمرر هذه المعلومات إلى GitHub في رابط المتصفح. لا تُرسل معاملات أو مبالغ أو أرقام حسابات أو رسائل أو معرف Android أو رقم تسلسلي للجهاز. يمكنك تعديل أو حذف الحقول قبل إرسال البلاغ.

GitHub والمتصفح لهما سياساتهما الخاصة. **هذا المستودع Public؛ البلاغ والصور والتعليقات التي تنشرها يمكن للجميع رؤيتها.** لا ترفق بيانات مالية حقيقية. افتح [دليل الإبلاغ](CONTRIBUTING.md) قبل المشاركة.
