# إزاي تبلغ عن مشكلة أو تقترح تحسين؟

التواصل هنا من خلال GitHub Issues، ولا تحتاج الانضمام لريبو كود التطبيق. تحتاج حساب GitHub لإرسال البلاغ أو التعليق.

## مشكلة

افتح [فورم المشكلة](https://github.com/MohamedGamal-Ahmed/Follow-Money-Support/issues/new?template=bug_report.yml)، واكتب:

- الصفحة أو الجزء اللي فيه المشكلة.
- خطوات تكرارها: فتحت إيه، اخترت أنهي فترة أو عملة، وضغطت على إيه.
- النتيجة اللي ظهرت والنتيجة اللي كنت متوقعها.
- نسخة Follow Money ونوع الجهاز وAndroid، وهل المشكلة بتحصل كل مرة.

لمشكلة حسابات أو تحليل، استخدم مثالًا مصطنعًا بنفس العلاقة الحسابية: مثلًا شراء 100، ومبلغ رجع لك 120، والمتوقع خصم 100 من الصرف واحتساب الفرق 20 في الدخل. لا تستخدم رسائلك الفعلية.

## اقتراح

افتح [فورم التحسين](https://github.com/MohamedGamal-Ahmed/Follow-Money-Support/issues/new?template=feature_request.yml). اشرح المشكلة في الاستخدام، واقتراحك، ومثال قبل/بعد لو ينفع.

## الصور والبيانات

كل البلاغات والتعليقات والمرفقات عامة. اخفِ الأسماء والهواتف والأرصدة وأرقام الحسابات والبطاقات والصورة الشخصية وخلفية الهاتف. لا ترفع رسائل أصلية، OTP أو نسخة قاعدة البيانات أو CSV مالي أو logcat كامل.

راجع البيانات التي ملأها التطبيق قبل الإرسال. تشمل النسخة والجهاز والنظام واللغة، ويمكنك حذفها من الفورم لو لا ترغب في مشاركتها.

تجنب تكرار البلاغات، وحافظ على النقاش متعلقًا بالمشكلة. قد نطلب مثالًا تجريبيًا أو خطوات إضافية قبل تأكيد العطل. للثغرات، اتبع [إرشادات الأمن](SECURITY.md).
