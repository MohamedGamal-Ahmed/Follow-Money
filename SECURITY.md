# Security reporting

Follow Money is a development app. This repository being private does not make an attachment safe to share: repository collaborators may read issues and CI artifacts.

Report suspected data exposure, unauthorized component access or source decryption problems directly to the maintainer through your existing private contact channel. Do not upload financial data, credentials or exploit details to issues. If GitHub's **Report a vulnerability** option is enabled for this repository, that private reporting channel may also be used; its availability is not assumed.

Include affected app/Android versions, a synthetic reproduction and the impact you observed. A fixed response time is not promised.

The latest development source is the maintained version; older APKs are not separately supported. Review [privacy and storage boundaries](docs/PRIVACY.md) before testing.
